# Core.Scrapper 🚀
Advanced production-grade command-line web scraper to extract structural HTML and styling blueprints from any website.

## ✨ Advanced Features
- **Anti-Bot Bypass Engine**: Integrated browser-mimicking headers to cleanly scrape strict platforms.
- **Deep HTML Structural Extraction**: Downloads raw prettified document maps.
- **Cascading CSS Collector**: Auto-resolves internal style nodes and pulls remote external stylesheets.
